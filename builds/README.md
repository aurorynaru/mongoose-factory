# Builds

One record per build-mode task: `BLD-NNN-<slug>.md`, started from
`.claude/skills/mongoose-builder/templates/build-brief.md` and completed with
`templates/build-record.md`. Evidence goes in `evidence/BLD-NNN/`.
See AGENTS.md "Build mode".

To request a build, fill in `.claude/skills/mongoose-builder/templates/build-request-prompt.md`
and paste it into Claude.
