## Creating a Validator object

Source: https://docs.infor.com/mg/2026.x/en-us/mongooseolh/mgwsolh_mg/cdm1496369868126.html

1. Launch the Web Designer.
2. Select **Edit** \> **Validator**.
3. Click the New (**\+**) button.
4. Specify a name for the new Validator object in the **Name** field.
5. Click **OK**. 

   The new Validator name displays in the list on the left panel, and the **Properties** panel on the right displays the property sheet for the new Validator object.
6. In the property sheet, specify the properties and attributes to be used by the new Validator object.
7. Click **OK**.

## Creating a Web User Control Asset object

Source: https://docs.infor.com/mg/2026.x/en-us/mongooseolh/mgwsolh_mg/tub1496370558234.html

1. Launch the Web Designer.
2. Select **Edit** \> **Web User Control Assets**.
3. Click the New (**\+**) button.
4. Specify a name for the new Web User Control Asset object in the **Name** field.

   To have the new asset created within a new or existing folder, type the entire path and file name here.

   For example, to have a new CSS file created inside a Mongoose folder, you would specify Mongoose/CSS/MyCssFile.css in the **Name** field.
5. Click **OK**. 

   The new Web User Control Asset name is displayed in the list on the left panel, and the **Properties** panel on the right displays the property sheet for the new Web User Control Asset object.
6. Select the type of content that the new asset in the **Content** drop-down list.
7. Click the ellipsis (**…**) button of the **Contents** field.
8. Use the **Edit Browser File** form to define the Web User Control Asset object. 

   **Note:** The **Edit Browser File** form displays different options, depending on what type of **Content** you specified.
9. Click **OK**.

## Modifying global objects in the Web Designer

Source: https://docs.infor.com/mg/2026.x/en-us/mongooseolh/mgwsolh_mg/pht1496371163480.html

You can modify most global objects in the Web Designer. The exceptions are Image objects: You can only import, export, or delete these objects.

The details vary slightly for each global object, but here is the basic procedure:

1. If you are using a source control system, make sure you have the global object you want to modify checked out.
2. Launch the Web Designer.
3. From the **Edit** menu, select the type of global object you want to modify.
4. In the global object editor form that opens, select the specific object to modify. 

   **Note:** In most cases, this involves clicking the Design button on the **Properties** sheet. (This is the icon that looks like a pencil.)
5. Modify the object as desired.
6. Click **OK**.
