## Creating a Build from Scratch form (Web Designer)

Source: https://docs.infor.com/mg/2026.x/en-us/mongooseolh/mgwsolh_mg/isi1501810350675.html

**Note:** This procedure is a continuation of the procedure for creating forms in the Web Designer. For the procedure to create a build-from-scratch form in Design Mode (Windows client), see [Creating a Build from Scratch form (Design Mode)](https://docs.infor.com/mg/2026.x/en-us/mongooseolh/mgwsolh_mg/lsm1454148017910.html).

To continue creating a Build from Scratch form in the Web Designer:

1. If you have not already done so, complete the steps in the topic [Creating a form in the Web Designer](https://docs.infor.com/mg/2026.x/en-us/mongooseolh/mgwsolh_mg/xul1496288205534.html) before continuing.
2. In the **Form Template \> Name** field, specify the name of the form. 

   You can do this either by selecting the name of a form template from the drop-down list or by typing a new name in the field.

   **Caution:** Be warned that, if you specify an existing form template, the Web Designer will overwrite your existing form with the new blank one. Once you click **Finish**, the old version is gone.
3. Verify that the **Form Type** is **BuildFromScratch**.
4. In the **Form Layout** drop-down list, select the position to be used for the grid part of the form.
5. From the **Device Type** drop-down list, specify what type of device you are creating the form for.
6. Optionally, from the **Data Source** drop-down list, specify the IDO to use as the source of data for your form.
7. Optionally, specify the name of the **Query Form** to be used in conjunction with your form. 

   This can also be specified later.
8. Optionally, add any **Comments** you want to associate with the form. 

   **Note:** Any comments you enter here do not display anywhere on the form. They are strictly for your information, perhaps to explain the reason the form was created or what it was created to do.
9. Click **Next**.
10. If you want to save the template for the form (in case you want to later recreate the form without having to start from the beginning), select the **Save Template** option.
11. Click **Finish**.

The Web Designer creates the form and opens it ready for further design action. You can now add components and arrange them according to your needs.
