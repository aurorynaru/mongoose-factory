## Objective (brief summary)

Test whether an existing FX_ Web User Control can invoke the existing FX_Echo C# Form Script method and read back the expected string through `WSForm.getVarValue`, using one Global Persistent variable `FX_vEcho`. Plan: create `FX_vEcho` (Global=True, Persistent=True); extend `FX_Echo` to set `FX_vEcho` to `"FX_ECHO:" + s` before its existing return; add `FX_BridgeStatus` to `FX_Bridge/index.html` (raw invoke callback value) and `WSForm.getVarValue("FX_vEcho")` into `FX_BridgeOutput`; one Save; one close/reopen; one runtime click. Success requires `FX_ECHO:bridge-probe` visible in `FX_BridgeOutput`.

Out of scope (brief): non-FX_ artifacts; `$app/scripts/UserControl.js`; Mock objects; `FX_InventoryPrototype01`; deletion of stale `UserCtrl*_userControl1_USER` variables; extra variables/methods/components; debugging the invoke callback value `0`; browser JavaScript.
